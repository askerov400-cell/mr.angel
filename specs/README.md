# Спецификации Хранителя

В этой папке хранятся спецификации изменений Telegram-бота «Хранитель».

Порядок работы: спецификация → реализация → проверка критериев готовности.

Для новой задачи создать отдельный Markdown-файл с понятным названием. Связанные задачи можно группировать в подпапки.

Минимальное содержание:

- Статус: черновик, готова к реализации, в работе или выполнена.
- Цель: какой результат нужен пользователю.
- Требования и ожидаемое поведение.
- Границы: что входит в задачу.
- Данные, безопасность и настройки, если применимо. Значения секретов не записывать.
- Открытые вопросы, если есть.
- Критерии готовности и результаты их проверки.

Выбранная основа проекта: Git, Supabase и Railway. Их настройка и переход с локального хранения требуют отдельных спецификаций; интеграции пока не считаются готовыми.
