# Git и первая публикация

Статус: выполнена.

## Цель

Сохранить код Хранителя в https://github.com/askerov400-cell/mr.angel.

## Требования

- Установить Git, если отсутствует, и инициализировать репозиторий в корне проекта.
- Исключить секреты, локальные данные, окружение, кеши, резервные копии и временные файлы до первого коммита.
- Проверить публикуемые файлы на секреты и персональные данные без вывода их значений.
- Создать первый коммит и отправить его в указанный репозиторий. Существующую удалённую историю не перезаписывать.
- Не менять поведение бота и не удалять локальные данные.

## Критерии готовности

- Git доступен, локальный репозиторий создан.
- `.env`, базы данных и файлы памяти/состояния исключены из Git.
- Проверен состав коммита и отсутствие секретов в публикуемых файлах.
- Коммит опубликован; удалённая ветка совпадает с локальной.

## Проверки

- Git установлен; локальная ветка `main` создана, `origin` настроен.
- Удалённый репозиторий проверен: веток пока нет.
- Проверены исключения `.env`, `.venv`, базы, памяти, состояния и резервной копии.
- Содержимое индекса проверено на значения локальных секретов и типовые токены: совпадений нет. Проверка формата изменений пройдена.
- Первый коммит опубликован в `origin/main`; GitHub подтвердил создание ветки и настройку отслеживания.
