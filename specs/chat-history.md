# Закрытая история переписки

Статус: в работе.

## Цель

По запросу пользователя ассистент может прочитать сообщения Telegram-боту и фактически отправленные ответы, без скриншотов.

## Требования

- Сохранять новые текстовые сообщения и команды из личного чата, а также ответы после успешной отправки Telegram.
- Таблица `chat_messages`: владелец, чат, ID сообщения Telegram, роль, текст и время записи. Повтор доставки не создаёт дубль.
- Не сохранять групповые чаты. История не подменяет память и не добавляется автоматически в контекст модели.
- Закрыть доступ публичным ролям; ключи и известные значения секретов скрывать до записи. Содержимое переписки не выводить в runtime-логи или Git.
- Ошибка журнала не прерывает ответ пользователю; безопасный лог сообщает только тип сбоя.
- Чтение ассистентом — по запросу пользователя, с фильтром владельца и ограничением количества записей. Это не постоянное наблюдение.
- Старые сообщения задним числом не импортируются. История хранится до отдельного удаления; автоматическая очистка в этот этап не входит.

## Проверки

- Запись входящего сообщения, команды и отправленного ответа.
- Идемпотентность по чату и ID сообщения.
- Отсутствие записи для групп и неотправленных ответов.
- Маскирование секретов и продолжение работы при сбое журнала.
