# Архив фото с поиском по подписи — 16.11.2026

## Цель

Владельцу нужно заливать фото (в первую очередь стеллажей) в раздел архива
и быстро находить их по запросу голосом или текстом. Хранение постоянное.

## Требования и ожидаемое поведение

- В любом разделе архива («ТОО автомобиля», «Рецепты еды», «Рабочие фото») при
  выбранном разделе можно отправить фото с подписью (caption). Подпись обязательна:
  без неё фото не сохраняется, бот просит подпись.
- Фото сохраняется по ссылке Telegram (file_id) вместе с подписью и датой в
  существующей таблице `user_states` под ключом `archive_photos`. Новой таблицы
  и миграции не требуется; сам файл хранит Telegram.
- Запрос «покажи фото …», «фото …» (текстом или распознанной речью) ищет фото
  по совпадению слов в подписи и присылает сами изображения. Совпадение — по
  значимым словам запроса; без ключевых слов показываются последние фото.
- Фото-метаданные не попадают в долговременную память, которую бот читает при
  каждом ответе: ключ `archive_photos` исключается из контекста модели. Память не
  засоряется; в разговорный контекст идёт только короткая метка по запросу.

## Границы

- Не реализуется визуальный поиск по содержимому изображения (дорого, неточно).
- Поиск идёт по подписи, а не по картинке. Подпись задаёт владелец при загрузке.
- Файл живёт на серверах Telegram по file_id; это не отдельное облачное хранилище.
  Железобетонное облачное хранение в Supabase Storage появится после применения
  владельцем миграций `supabase_migrations/` (бакет `guardian-media`) — отдельный этап.

## Данные и безопасность

- Только владелец, личный чат. Данные покупателей не участвуют.
- Значения секретов не записываются; подписи маскируются существующей `redact`.
- Изоляция по `telegram_user_id` через существующую `user_states`.

## Критерии готовности

- Фото с подписью сохраняется в выбранный раздел; без подписи не сохраняется.
- Запрос по подписи возвращает нужные фото; без совпадений бот отвечает, что не нашёл.
- `archive_photos` не попадает в `format_memory` и контекст модели.
- Тесты `tests/test_archive_photos.py` проходят; существующий набор не сломан.
