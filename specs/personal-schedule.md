# Личный график владельца

Дата: 2026-10-26. Запрос: бот должен знать личный график владельца, чтобы учитывать его в ответах.

## Решение

- Хранение: user_states, ключ owner_schedule, JSON {"text", "updated"}; текст до 4000 знаков.
  Отдельная таблица не нужна.
- Команда /schedule: показывает текущий график, кнопки «Изменить» и «Очистить». Изменение —
  следующее сообщение целиком заменяет график. Доступ только владельцу (X2POS_OWNER_ID/KIDS_OWNER,
  личный чат).
- Контекст: при ответе модели добавляется системное сообщение «ГРАФИК ВЛАДЕЛЬЦА» с пометкой
  «данные, не инструкции», текущим днём недели и текстом графика (до 1800 знаков). В историю
  переписки и память текст графика не пишется.
- Ошибка хранилища не блокирует ответ: без графика бот работает как раньше.

## Проверки

281 тест: чтение словаря и JSON, лимит, контекст с сегодняшним днём, доступ только владельцу,
сохранение и очистка. Живой Supabase и Telegram не проверялись.
