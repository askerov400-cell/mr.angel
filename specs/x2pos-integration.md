# X2POS: чтение учёта через Хранителя

Статус: реализация; реальное подключение ожидает настройки доступа.

Источник: предоставленный владельцем документ API v1.6 (43 страницы).
Адрес фиксирован: https://x2pos.com; авторизация API-KEY в заголовке.
POST /api/auth (form-data user/password) возвращает token и company_id.
Пароль не хранить; отдельная локальная утилита получает токен и сохраняет только
токен и идентификаторы в игнорируемом .env. Реальный ключ не включать в код,
документацию, журнал и ответы Telegram.

Первый этап: отдельная кнопка X2POS, /x2pos, проверка подключения,
товары с розничными/оптовыми ценами, остатки выбранного филиала,
документы приёмки, перемещения, списания и ревизии.
Только личный чат X2POS_OWNER_ID. Без настройки владельца доступ закрыт.
На сервере: X2POS_API_KEY, X2POS_OWNER_ID, X2POS_BRANCH_ID,
X2POS_USER_ID (для документов). ID филиала сверять со списком доступа /api/employee.
Не использовать примеры ключей и идентификаторов из документа как реальные.

GET /api/products: page с 1, 50 разновидностей на странице.
В примере variations записано синтаксически неверно; поддержать JSON-массив и
словарь разновидностей, и отклонять другие формы до показа данных.
GET /api/stock: branch_id; остатки связаны с variation_id, не product_id.
Не считать отсутствие записи остатка нулём. Показывать «нет данных».
GET /api/procurements: API-KEY, User-Id, Branch-Id; action, page, per_page=10.
Показывать только ID, даты, тип, статус, количество и сумму; контакты, сотрудники,
платежи и заметки не передавать в память и LLM.
Списки обрабатывать с ограничением размера; ошибки не превращать в пустые данные.

Запросы по нажатию, максимум 10 секунд сетевого ожидания, без повторов,
редиректы запрещены, TLS проверяется. Статус ожидания сразу в Telegram.
Без изменения учёта, финансов и цен; без фоновой синхронизации или новой БД.
Просмотр товаров: 50 разновидностей API, показ по 10 через короткие кнопки.
Список движений: 10 документов на страницу, явно последние 7 дней по API.

Критерии: отказ чужому/группе, безопасная ошибка при отсутствии настроек,
верный заголовок и методы, страницы/variation_id, проверка филиала,
некорректные ответы не считаются успехом, нет утечки ключа через ошибки/редиректы.
Реальное чтение проверять после получения ключа, отдельно от локальных тестов.

Проверено: 120 локальных тестов проходят, включая 11 тестов X2POS; компиляция Python проходит. Ключ отсутствует, реальный доступ и форма variations пока не проверены. Внедрение чтения подготовлено, подключение не заявляется успешным.
