# Команды без зависимости от оформления

Статус: в работе.

- `/memory` и `/clear`, отправленные отдельным сообщением, обрабатываются приложением даже без Telegram-entity bot_command (например, с оформлением code).
- Допускаются пробелы вокруг команды. Упоминание собственного бота разрешено; чужого — не выполняется.
- Для безопасного показа памяти допускается одна завершающая точка: `/memory.`. Для `/clear` это исключение не применяется.
- Существующие проверки личного чата для памяти сохраняются.
- Команду не отправлять классификатору и отвечающей модели.
- Сообщение с дополнительным текстом не считать такой командой.
- Журнал переписки сохраняет вход и фактический ответ как раньше.

Проверки: обработка без entity, очистка только текущего диалога, отказ чужому боту и дополнительному тексту.
